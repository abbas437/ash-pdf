# Markup + comment

Markup + comment circles an item with a dotted line and puts a short comment in a box beside it, joined to the ring. It is meant for review mark-up on drawings, where a revision cloud would hide the sheet.

[Show me](#showme:tool:markup)

## Mark up an item

1. Press <kbd>M</kbd> or click the Markup + comment tool (it sits next to Callout).
2. In the options bar, choose **Ellipse** or **Rectangle**.
3. Drag over the item. A dotted outline previews the shape.
4. Release. A comment box opens beside the shape: to the right if there is room, otherwise to the left.
5. Type the comment, then click away.

A plain click without dragging does nothing.

The leader line is re-aimed at the edge of the shape as the box grows. If you leave the comment empty, only the dotted shape is kept.

## Options

[Show me the options bar](#showme:panel:options-bar)

| Option | What it does |
| --- | --- |
| Ellipse / Rectangle | Shape of the dotted outline |
| Colour chips and custom colour | Red, blue (Rev. comment), green, orange or your own |
| Border | Style of the comment box border |
| Fill | White, None or Pale yellow box |
| Size | Comment text size in points |

> **Tip:** Use the blue chip for follow-up comments on a resubmission, so they stand out from the original mark-up.

The shape itself is always drawn dotted. The Border option applies to the comment box.

## One undo step

The shape and its comment are added together, so a single <kbd>Ctrl</kbd>+<kbd>Z</kbd> removes both. See [Undo and redo](#topic:undo-redo).

> **Note:** The tool has no approval or status field of its own. To record a review result, use the colour chips as your convention, or the [Comments panel](#topic:comments-panel).

Afterwards the shape and the comment are separate objects: select either with the Select tool to restyle or move it. The comment text uses the same right-click formatting as [Callouts](#topic:callouts).
