# Save and print

## Save

1. Press <kbd>Ctrl</kbd>+<kbd>S</kbd>, or click **Save**. [Show me](#showme:btn:save)
2. The file is written in place and a message confirms **Saved** with the file name.

To keep the original, use **Save as…** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>) and choose a new name. [Show me](#showme:btn:saveas) A document that has no file yet always asks for a name. If the original sits in a folder the app may not write to, Save falls back to Save As.

## Signed documents

Saving over a digitally signed file can break its signature.

- If you only added annotations, the app appends them as an update and shows **Saved as an update; the signature is kept**.
- If a full rewrite is needed (after a page operation, or for a document certified against changes), a dialog asks first. Choose **Save as a copy…** to keep the signed original, **Overwrite original** to accept the loss of the signature, or **Cancel**.

## Closing with unsaved changes

A dot on the tab marks unsaved changes. Closing it opens **Unsaved changes** with **Save**, **Don't save** and **Cancel**. Quitting the app with unsaved tabs also asks you to confirm.

## Encrypted documents

An encrypted document opens as **Read-only document**: you can view and print it, but Save is refused because editing is not supported.

## Print

1. Press <kbd>Ctrl</kbd>+<kbd>P</kbd>, or click **Print**. [Show me](#showme:btn:print)
2. Set the options below, then click **Print…**.

| Option | Choices |
| --- | --- |
| Pages | All pages, Current page, Page range, Odd pages, Even pages |
| Range | For Page range, for example `1-3, 5` |
| Scaling | Fit to paper (default), Actual size |
| Include annotations | Yes (default), No |
| Copies | 1 to 99 |

> **Note:** Unsaved annotations are included in the printout when **Include annotations** is Yes.

See also [Undo and redo](#topic:undo-redo) and [Signatures](#topic:signatures).
