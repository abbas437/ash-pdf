# Work with page thumbnails

The Thumbnails tab in the sidebar shows every page of the document. It is the quickest place to select pages and change them.

## Show the thumbnails

1. Press <kbd>Ctrl</kbd>+<kbd>B</kbd> or <kbd>F4</kbd> to show or hide the sidebar, or use [the sidebar button](#showme:btn:sidebar).
2. Choose [the Thumbnails tab](#showme:panel:thumbnails).

## Select pages

| Action | Result |
| --- | --- |
| Click a thumbnail | Selects that page only and goes to it |
| <kbd>Ctrl</kbd>+click | Adds or removes one page |
| <kbd>Shift</kbd>+click | Selects the range from the last page you clicked |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Selects every page (with a thumbnail focused) |

## Use the right-click menu

Right-click a thumbnail. The menu header reads "Page N" or "N pages selected", and every command applies to that selection.

| Command | What it does |
| --- | --- |
| Rotate left / Rotate right | Turns the pages (keys <kbd>[</kbd> and <kbd>]</kbd>) |
| Insert blank page before / after | Adds an empty page next to the selection |
| Duplicate page(s) | Copies the pages in place |
| Extract pages… | Saves the pages as a new PDF |
| Move up / down / to start / to end | Moves the pages within the document |
| Delete page… | Removes the pages (<kbd>Del</kbd>) |

## Reorder by dragging

Drag one or more thumbnails to a new position; a line shows where they will land.

## Copy pages to another document

1. Select the thumbnails.
2. Drag them onto another tab in the tab bar. The tab opens after a short pause.
3. Drop them on that document's thumbnails. Copies are inserted at the line; the original is unchanged.

## Undo a change

After each page change an Undo toast appears for a few seconds. Click **Undo**, or use Edit ▸ Undo. See [Undo and redo](#topic:undo-redo).

> **Note:** Page commands are disabled for read-only documents.
