# Comments panel

The **Comments** tab in the sidebar lists every annotation in the open document, grouped by page, with its author, date, comment, replies and review status. [Show me](#showme:panel:comments)

## Open the list

1. Click the **Comments** tab (speech-bubble icon) in the sidebar.
2. Click any entry to scroll to its page and select the mark.

Each entry shows the type of mark, the author, the date ("Not saved" until you save the file), the comment text and any replies.

## Find comments

| Control | What it does |
|---|---|
| Search comments | Matches comment text, reply text and author names |
| Sort | Page (default, grouped by page), Date (newest first) or Author (A to Z) |
| All types | Show one kind of mark only, such as Rectangle or Callout |
| All authors | Show one author only |
| All statuses | Show Accepted, Rejected, Cancelled, Completed or None |

## Work on a comment

1. **Edit** opens the comment for the selected mark.
2. **Reply** opens a Reply box; your reply is added under the comment with your [Author name](#topic:author-name) and the time.
3. The status menu sets Accepted, Rejected, Cancelled, Completed or None. A status badge appears on the entry.
4. **Delete** removes the mark with its comment and replies after you confirm.

Each change is one undo step: see [Undo and redo](#topic:undo-redo). In a read-only document these buttons are disabled.

## Export the list

Choose **Export…** to save the entries currently shown (after search and filters) as a CSV file named `<document>-comments.csv`. Columns are page, type, author, date, status, comment and replies. Open it in a spreadsheet to build a comment register.

> **Tip:** Filter by status before exporting to produce, for example, a list of open comments only.

> **Note:** Comments are written into the PDF, so other PDF readers can show them. To add comments, see [Sticky notes](#topic:sticky-notes), [Callouts](#topic:callouts) and [Add a comment to any mark](#topic:markup-comment).
