Use the **Text** tool to type new text anywhere on a page. [Show me](#showme:text)

![The Text tool on the toolbar](img/toolbar-edit.png)

1. Choose the Text tool on the toolbar, or press <kbd>T</kbd>.
2. Click on the page where the text should start, then type.
3. Press <kbd>Ctrl</kbd>+<kbd>Enter</kbd> or click outside the box to finish.

## Text options

| Option | What it does |
| --- | --- |
| Font | The typeface of the text |
| Size | Text size in points |
| Colour | Text colour |

> [!NOTE]
> The text becomes part of the page when you save. The tool keys are listed in [Keyboard shortcuts](#topic:keyboard-shortcuts/tools).
