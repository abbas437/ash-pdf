# Callouts

A callout is a comment box joined by a leader line and arrowhead to the item it refers to. It is the quickest way to say "this, here, needs changing".

[Show me](#showme:tool:callout)

## Add a callout

1. Press <kbd>C</kbd> or click the Callout tool.
2. Press on the item the comment is about. The arrowhead will point here.
3. Drag to where the comment should sit. A preview of the box follows the pointer; the box opens to the right and below the drag end, or to the left and above it, depending on direction.
4. Release and type the comment.
5. Click away to finish. An empty callout is discarded.

A click without dragging also works: the box is placed up and to the right of the point you clicked.

## Options

[Show me the options bar](#showme:panel:options-bar)

| Option | What it does |
| --- | --- |
| Review mark-up | A hint only: use dotted markup with a short comment, and the blue chip for follow-up review comments |
| Colour chips | Red, blue (Rev. comment), green or orange; the box border, leader and text use it |
| Custom colour | Any other colour |
| Border | Solid, Dotted or Dashed |
| Fill | White, None or Pale yellow |
| Size | Text size in points (4 to 72) |

Select a callout with the Select tool and change these options to restyle it. While a comment is open, changing an option also restyles the text being typed.

## Format the text

While you type the comment:

- The box grows with the text.
- Right-click opens the same formatting menu as a text box: Cut, Copy, Paste, Select all, Bold, Italic, Underline, Strikethrough, and Font, Size and Colour.
- Unlike a text box, a callout does not accept pictures, so there is no Insert picture item.

See [Text boxes](#topic:text-boxes) for the full formatting menu.

## Move and resize

With the Select tool, drag the box to move it together with its tip. Drag the tip handle to re-aim the arrow, or the box handles to resize it.

> **Tip:** To circle the item as well, use [Markup + comment](#topic:markup-comment), which draws the dotted ring and the callout in one step.

Callouts appear in the [Comments panel](#topic:comments-panel). Use [Undo and redo](#topic:undo-redo) to take one back.
