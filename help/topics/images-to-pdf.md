# Create a PDF from images

You can turn PNG and JPG files into a PDF with one page per image. You do not need a document open first.

## Steps

1. Choose **File ▸ Images to PDF…**
2. Click **Add images…** and select one or more PNG or JPG files. Other file types are refused with a message.
3. Check the list. Pages follow the order listed.
4. Choose a **Page size**.
5. Leave **Make searchable (recognize text, English)** ticked if you want to search or copy the text, or untick it to skip recognition.
6. Click **Create PDF**.

If the list is empty, the dialog asks you to add at least one image.

| Page size | Result |
| --- | --- |
| Fit to image | Each page matches its image, with no margin |
| A4 | A4 pages with a small margin |
| Letter | Letter pages with a small margin |

## The result

The new PDF opens in a **new tab**, so your current document is not changed. It takes its name from the first image. With more than one image, `-images` is added to the name.

Text recognition is on by default and runs after the PDF opens, so a large set of images can take a while. It recognises English only. For other options and limits, see [OCR](#topic:ocr).

> **Tip:** Scanned pages in the wrong order or orientation can be fixed afterwards. See [Rotate, reorder, reverse and interleave](#topic:rotate-reorder-reverse-interleave).

Remember to save the new tab. See [Save and print](#topic:save-and-print).
