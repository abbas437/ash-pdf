dependency is not under MIT, Apache-2.0, BSD-2/3-Clause, ISC, 0BSD, OFL-1.1, Unlicense, CC0-1.0,
BlueOak-1.0.0 or Zlib — so a GPL, AGPL, LGPL, MPL or unknown licence cannot slip in.

pdf.js also ships Liberation Sans 1.x, which is GPL-2.0 with a font exception. It does not meet our
font policy (OFL / Apache / MIT, plus BSD from the dependency allow-list), so `scripts/vendor.js` does
not copy it; non-embedded Helvetica/Arial is drawn with the system sans-serif font. Any font added later
must be OFL-1.1, Apache-2.0 or MIT and listed here.

## The PDF format

PDF is an open ISO standard (ISO 32000-1 and ISO 32000-2) and free to implement. Using "PDF" as the
name of the file format is fine.

## Trademarks

- "Adobe", "Acrobat", "Adobe Reader" and the Adobe PDF icon are Adobe trademarks. The app, its icon,
  installer, website and documentation use none of them and must not imitate Adobe's UI branding
  (red page-with-swirl icon, Acrobat colour scheme or naming). Do not describe the app as
  "Acrobat-compatible" or "Adobe PDF"; "opens PDF files" is fine.
- The icon is original (ink-green square, stone page, brass "ASH" mark) and avoids Adobe and Autodesk
  imagery.
- **"ASH PDF Studio" has not been through a trademark search.** Before a wide launch the owner should
  run a search (e.g. WIPO Global Brand Database, USPTO, EUIPO and the Saudi SAIP register) for
  conflicts in software classes 9 and 42.

## Code signing

The Windows executables are **unsigned**. Windows SmartScreen will warn ("Windows protected your PC")
until an Authenticode code-signing certificate is bought and the build signs the files. The README
says this plainly and tells users how to check the SHA-256 checksums published with each release.
