# Replacing text

**Tools > Replace text…** covers a piece of the page with a white box and puts a new text box in the same place, so you can type a correction over the original wording.

## Replace a piece of text

1. Choose **Tools > Replace text…**. [Show me](#showme:menu:Tools)
2. Read the note in the **Replace text** dialog and click **Draw rectangle**.
3. Drag a rectangle over the text you want to replace.
4. Type the new text. The font size starts at about 80% of the rectangle's height.
5. Press <kbd>Ctrl</kbd>+<kbd>Enter</kbd> or click outside the box to finish.

If you leave the new text empty, or press <kbd>Esc</kbd>, the white box is removed as well.

The result is two separate objects, a whiteout and a text box, that you can select, move or delete like any others. Format the new text as described in [Adding and formatting text boxes](#topic:text-boxes).

## The original text stays in the file

> **Important:** Replace text only hides the original wording. It is not deleted from the PDF and can still be found, selected or copied by anyone who receives the file.

To remove confidential text for good, use **Redact** instead: see [Whiteout and redaction](#topic:redaction).
