# Keyboard shortcuts

This is the complete list of keys in ASH PDF Studio. On macOS, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>. Press <kbd>F1</kbd> at any time to open Help. The shorter list under Help ▸ Keyboard shortcuts shows only the most common keys.

> **Tip:** Single-letter keys only work when you are not typing in a text box, field or dialog, and no dialog is open.

## Files & tabs

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a file |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New window (desktop app only) |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save as |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the current tab |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Next tab (add <kbd>Shift</kbd> for the previous tab) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>PageUp</kbd> / <kbd>PageDown</kbd> | Move the current tab left / right |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Preferences |
| <kbd>F1</kbd> | Help |

See [Open files and use tabs](#topic:open-and-tabs).

## View & navigation

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> (or <kbd>Ctrl</kbd>+<kbd>+</kbd>) | Zoom in |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom out |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Fit page |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | Actual size |
| <kbd>Home</kbd> / <kbd>End</kbd> | First / last page |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Previous / next page |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> or <kbd>F4</kbd> | Show or hide the sidebar |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | [Find](#topic:find-and-search) in the document |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | [Advanced Search](#topic:advanced-search) |
| Hold <kbd>Space</kbd> | Temporary Hand tool for dragging the page |

In the find bar: <kbd>Enter</kbd> goes to the next match, <kbd>Shift</kbd>+<kbd>Enter</kbd> to the previous one, and <kbd>Esc</kbd> closes the bar. See [Navigate and zoom](#topic:navigate-and-zoom).

## Editing text boxes

These work while you are typing in a Text tool box.

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Bold |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Italic |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Underline |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Strikethrough |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo within the box |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo within the box |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Finish the box |
| <kbd>Esc</kbd> | Cancel the box |

> **Note:** <kbd>Ctrl</kbd>+<kbd>B</kbd> toggles the sidebar only when you are not typing. See [Text boxes](#topic:text-boxes).

## Pages / thumbnails

Click a thumbnail in the sidebar first.

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all pages |
| <kbd>Delete</kbd> | Delete the selected pages |
| <kbd>]</kbd> | Rotate the selected pages 90° clockwise |
| <kbd>[</kbd> | Rotate the selected pages 90° anticlockwise |

See [Page thumbnails](#topic:page-thumbnails).

## Objects (group, copy, delete, undo)

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Group the selected objects |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Ungroup |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the selection |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected objects, or the selected page text |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cut the selected objects |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all text on the page (with the page focused) |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selected objects |
| <kbd>←</kbd> <kbd>↑</kbd> <kbd>→</kbd> <kbd>↓</kbd> | Nudge the selection by 1 unit (<kbd>Shift</kbd> for 10) |
| <kbd>Enter</kbd> | Add or edit a comment on the single selected object |
| <kbd>Esc</kbd> | Cancel the current drag, or clear the selection and return to Select |

See [Select, group and clipboard](#topic:select-group-clipboard) and [Undo and redo](#topic:undo-redo).

## Reading mode

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Turn reading mode on or off |
| <kbd>F11</kbd> | Full screen on or off |
| <kbd>Esc</kbd> | Leave reading mode or full screen |
| <kbd>→</kbd> or <kbd>Space</kbd> | Next page |
| <kbd>←</kbd> or <kbd>Shift</kbd>+<kbd>Space</kbd> | Previous page |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Scroll down / up a line |
| <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>Page Up</kbd>, <kbd>Page Down</kbd> | As in normal view |
