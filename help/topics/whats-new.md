# What's new

The most recent additions, newest first. Versions up to 0.2.10 are tagged in the project history. Changes after that are grouped by release as far as the history shows.

## Version 0.2.15

- **Text box frame.** Give a text box a border, a fill colour and an inner margin, as in Word. See [Text boxes](#topic:text-boxes).
- **Pictures inside text boxes.** Paste a picture or use **Insert picture** in the right-click menu. Click a picture to select it, and use the **Picture size** menu to resize it. Damaged or recompressed picture data no longer causes problems, and photos taken with a rotated camera open upright.
- **Group and Ungroup.** Combine several objects and resize them as one. Ctrl+G groups the selection. See [Select, group and clipboard](#topic:select-group-clipboard).

## Version 0.2.14

- **A text cursor while you edit.** Inside a text box you now get the normal text cursor. Drag the frame around the box to move it.
- **Live colour on selected text.** Changing colour on selected words shows at once, and a run of colour changes undoes in one step.

## Version 0.2.13

- **Rich text formatting.** Make selected words bold, italic, underlined, struck through, or change their font, size and colour. A floating format bar and the usual shortcuts are available.
- **Right-click menu in the text editor.** Cut, Copy, Paste and the formatting choices are in one menu.
- **Eight resize handles.** Text boxes and callouts resize from every side and corner. A height you drag is kept as the minimum.
- The formatting is saved in the PDF, so other programs can read it.

## Version 0.2.12

- **Ctrl+click** adds an object to the selection or removes it.
- **Ctrl+drag** places copies and leaves the originals, as in Word.
- **Drop a PDF onto a document** to insert it at that point, and drag pages between tabs to copy them.
- File dialogs open in the last folder you used.

## Earlier

Versions 0.2.1 to 0.2.10 are tagged individually; open the project's releases page for their notes. For a problem with any version, see [Troubleshooting](#topic:troubleshooting).
