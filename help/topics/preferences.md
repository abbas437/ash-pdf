# Preferences

Preferences hold your default settings in one dialog.

## Change a setting

1. Choose **Edit** ▸ **Preferences…**, or press <kbd>Ctrl</kbd>+<kbd>,</kbd>.
2. Pick a section on the left: **General**, **Documents**, **Annotations** or **Toolbar**.
3. Change the options, then click **OK**. **Cancel** discards your changes.

**Reset to defaults** puts every option back to its default in the dialog; nothing is kept until you click **OK**.

## General

| Option | Choices (default first) |
| --- | --- |
| Theme | Light, Dark |
| On start-up | Ask, Restore last session, Start empty |
| Open files in | New tab, New window |

## Documents

| Option | Choices (default first) |
| --- | --- |
| Default zoom | Fit width, Fit page, 100 %, Last used |
| Show the sidebar when a document opens | On |
| Offer to recognize text when a scanned document opens | On |

## Annotations

| Option | Choices (default first) |
| --- | --- |
| Author name | Empty, which uses the built-in author name (up to 120 characters) |
| Default stamp shape | Rectangle, Rounded, Circle, Ellipse |
| Ask before applying a signature to the page | Off |

## Toolbar

| Option | Default |
| --- | --- |
| Show tool labels under the icons | Off |
| Coloured tool icons | On |

> **Tip:** The same two toolbar options are in the **View** menu as **Show tool labels** and **Coloured tool icons**. To choose which buttons appear, see [Customize the toolbar](#topic:customize-toolbar).

## Where settings are kept

Settings are stored on your computer by the app. With the portable build, they are kept in an `ASH-PDF-Studio-data` folder next to the .exe, so they travel with it on a USB stick and nothing else is left on the PC.
