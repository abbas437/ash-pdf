# Find text in a document

The find bar searches the text of the open document, highlights every match on the pages and lists them in the sidebar.

## Search the document

1. Open a document, then press <kbd>Ctrl</kbd>+<kbd>F</kbd>, choose Edit ▸ Find…, or [click the Find button](#showme:btn:find) on the toolbar.
2. Type your text in the **Find in document** box. The search starts a moment after you stop typing.
3. Press <kbd>Enter</kbd> to go to the next match or <kbd>Shift</kbd>+<kbd>Enter</kbd> to go back to the previous one. You can also use the **Next match** and **Previous match** buttons.
4. Press <kbd>Esc</kbd>, or use the **Close** button, to close the bar. Closing it clears the highlights.

The counter beside the box shows your position, for example "3 of 12". It reads "Searching…" while the search is running and "No results" when nothing matches.

## Options

| Button | Effect |
| --- | --- |
| **Aa** (Match case) | Only matches the same capitalisation |
| **W** (Whole words) | Skips matches inside longer words |

Spaces in your search match any run of spaces or line breaks, so a phrase still matches when it wraps onto a new line.

## The Search results list

Each match appears in the **Search results** tab of the sidebar with its page number and a little surrounding text. Click an entry to jump to that match.

> **Note:** Find only searches text that the PDF contains. A scanned page that is only a picture has no text to find.

## Mark every result for redaction

If you are preparing a document for release, you can turn all the matches into redaction marks at once.

1. Search for the word or phrase.
2. In the Search results tab, click **Mark all for redaction**.
3. A message tells you how many areas were marked. They are black boxes that you can still review and undo.
4. Choose Document ▸ Apply redactions… when you are ready to remove the content permanently.

> **Tip:** Marking is one undoable step, so <kbd>Ctrl</kbd>+<kbd>Z</kbd> removes all the marks together. Nothing is removed from the file until you apply the redactions. See [Redaction](#topic:redaction).

## Searching more than one document

To search every open document, or all the PDFs in a folder, use [Advanced Search](#topic:advanced-search). All shortcuts are listed under [Keyboard shortcuts](#topic:keyboard-shortcuts).
