# Author name

Your author name is written into every annotation, reply and dynamic stamp you save, so other reviewers can see who made each comment. It appears in the [Comments panel](#topic:comments-panel).

## Set your author name

1. Choose **Edit ▸ Author name…**.
2. Type your name in the **Author name** box (up to 200 characters).
3. Choose **OK**.

You can also set it in **Edit ▸ Preferences… ▸ Annotations ▸ Author name**. Both places change the same setting. See [Preferences](#topic:preferences).

> **Note:** If you leave the box empty, the application uses its built-in default name.

> **Tip:** Set your name before you start marking up. Dynamic [stamps](#topic:stamps) can print it on their second line.
