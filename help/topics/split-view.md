# Split view

Split view shows two documents (or two parts of the same document) at once. Each pane has its own scrolling, zoom and current page, so you can compare drawings or read one page while editing another.

## Open a split

1. Open a document. [Show me](#showme:btn:split)
2. Click **Split** on the toolbar, then choose **Split**. With one document open it appears in both panes; with several open, the current document is paired with the one you used just before.

You can also use the **View** menu: **Split vertically** (side by side) or **Split horizontally** (top and bottom).

## Choose what each pane shows

The **Split** button menu offers:

| Item | What it does |
| --- | --- |
| Split | Starts a split (shown only while not split). |
| Split this document | Shows the current document in both panes. |
| Side by side with | Lists your other open documents; click one to pair it with the current document. |
| Choose documents… | Opens the **Split view** dialog: pick the document for **Left / top pane** and **Right / bottom pane**, and choose vertical or horizontal. |
| Split horizontally | Starts a top-and-bottom split (shown while not split). |
| Switch to horizontal / vertical | Changes the orientation of an open split. |
| Close split | Returns to a single pane. |

Each pane also has a picker at its top for changing the document it shows. Choosing a tab in the tab strip while split puts that document in the focused pane.

## Resize the panes

Drag the divider between the panes. Double-click it to return to 50 / 50.

## Close the split

Choose **View** ▸ **Unsplit**, or **Close split** in the **Split** button menu. If you close a tab that one pane is showing, that pane switches to another open document; if none is left, the split closes.

> **Note:** The focused pane is the active document. Tools, menus and the status bar act on it. The pane you last worked in is the focused one.

> **Tip:** The **Split** button looks pressed while a split is open.
