# Select, group, copy and paste objects

The Select tool works on the objects you have added to a page: text boxes, images, shapes, stamps and signatures. It does not change the original text of the PDF (see [Edit text](#topic:edit-text)).

[Show me the Select tool](#showme:tool:select)

## Select and move

1. Choose **Select** on the toolbar, or press <kbd>V</kbd>.
2. Click an object to select it. Eight handles appear around it.
3. Drag the object to move it, or drag a handle to resize it.
4. Press <kbd>Delete</kbd> (or <kbd>Backspace</kbd>) to remove the selection.

| To do this | Do this |
| --- | --- |
| Add or remove an object from the selection | <kbd>Shift</kbd>+click it |
| Add an object | <kbd>Ctrl</kbd>+click it (on a selected object, <kbd>Ctrl</kbd>+click removes it) |
| Copy while moving | Hold <kbd>Ctrl</kbd> and drag; the originals stay, as in Word or PowerPoint |
| Duplicate | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| Nudge by 1 point | Arrow keys |
| Nudge by 10 points | <kbd>Shift</kbd>+arrow keys |
| Deselect | Click empty page, or <kbd>Esc</kbd> |

> **Note:** There is no drag-a-box selection. Select several objects with <kbd>Shift</kbd>+click or <kbd>Ctrl</kbd>+click, or use **Select all** in the page menu below. Text markups (highlights and similar) can be selected but are not moved by dragging or the arrow keys.

Press <kbd>Enter</kbd> with an object selected to add a comment to it (Edit menu, **Comment on selection…**).

## Group and ungroup

A group lets you treat several objects as one.

1. Select two or more objects.
2. Press <kbd>Ctrl</kbd>+<kbd>G</kbd>, or choose **Edit ▸ Group**, or right-click and choose **Group**.
3. To split it again, press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> or choose **Ungroup**.

A group is selected, moved, copied and resized as one. It has eight handles around the whole group; drag any handle to scale every member. Hold <kbd>Shift</kbd> on a corner handle to keep the proportions. Grouping and ungrouping are each one undo step ([Undo and redo](#topic:undo-redo)).

> **Important:** Signature blocks (see [Signatures](#topic:signatures)) cannot be grouped, ungrouped or stretched as a group.

## The page right-click menu

Right-click the page for **Cut**, **Copy**, **Paste**, **Delete**, **Select all** (every object on that page), **Group** and **Ungroup**. Items that do not apply are greyed out. In a read-only document the editing items are unavailable.

## Cut, copy and paste

- **Ctrl+X, Ctrl+C, Ctrl+V** work on selected objects. Paste puts them at the right-click point, or at the centre of the view when you use the keyboard.
- If the clipboard holds plain text copied elsewhere, pasting makes a text box in the current text style ([Text boxes](#topic:text-boxes)).
- If it holds only an image, pasting places an image, no larger than half the page ([Images](#topic:images)).
- Copying selected text from the page copies that text instead of objects.

> **Tip:** The original text of the PDF cannot be cut. The menu shows "Use Edit text (D) to change the document's text"; follow that advice.
