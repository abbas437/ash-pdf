# Highlight, underline, strike out and squiggle text

Four tools mark the text itself, character by character. They only work on pages that have a text layer, and the press must be on or next to text.

| Tool | Key | Default colour |
| --- | --- | --- |
| Highlight text | <kbd>H</kbd> | Yellow, 40% opacity |
| Underline text | <kbd>U</kbd> | Green |
| Strikeout text | <kbd>K</kbd> | Red |
| Squiggly underline | <kbd>G</kbd> | Green |

[Show me](#showme:tool:text-highlight)

## Mark text by dragging

1. Press <kbd>H</kbd>, <kbd>U</kbd>, <kbd>K</kbd> or <kbd>G</kbd>, or click the tool on the toolbar.
2. Press at the start of the text and drag to the end. A preview follows the pointer.
3. Release. One markup is added, running in reading order across lines (and pages) from where you pressed to where you released.

To mark a single word, double-click it with the tool active. A plain click does nothing.

## Mark text you have already selected

1. With the Select tool, select text on the page.
2. Pick the markup tool. The selection is converted straight away.

> **Tip:** <kbd>H</kbd> highlights selected text only when text is selected. With no text selected, <kbd>H</kbd> picks the area highlighter instead.

## Highlight text or Highlight area

[Highlight area](#showme:tool:highlight) draws a rectangle you size yourself, so it also works on scanned pages and drawings with no text. Highlight text follows the characters exactly. Use the text version whenever the page has real text.

## Options

With a tool active, the options bar offers:

| Option | Effect |
| --- | --- |
| Colour | Colour of the next markup |
| Opacity | How strongly it covers the text (0.1 to 1) |

[Show me the options bar](#showme:panel:options-bar)

To restyle a markup you have already made, select it with the Select tool and change the options.

> **Note:** Text markups are fixed to their text. You can select, restyle, comment on and delete them, but you cannot move or resize them.

To attach a comment to a markup, select it and press <kbd>Enter</kbd>; see [Sticky notes](#topic:sticky-notes) and [Comments panel](#topic:comments-panel). To remove one, select it and delete it, or use [Undo and redo](#topic:undo-redo).
