## Files

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print |
| <kbd>F1</kbd> | Help for the part of the window under the mouse |

## Tools

| Keys | Tool |
| --- | --- |
| <kbd>V</kbd> | Select |
| <kbd>Q</kbd> | Hand |
| <kbd>T</kbd> | Text |
| <kbd>N</kbd> | Sticky note |
