# Document properties

There are two separate commands: one shows information, the other changes it.

## View document properties

Choose **File ▸ Document properties**. The dialog is read-only. Click **Close** when you have finished.

| Row | Shows |
| --- | --- |
| Title, Author, Subject | The values stored in the file |
| Producer | The program that created the PDF |
| Pages | Number of pages |
| Page size | Size of the current page, in points and millimetres |
| File size | Size of the document |
| Encrypted | Yes or No |
| File | Where the file is saved, or its name if it has not been saved |

A dash means the field is empty.

## Edit document properties

1. Choose **Tools ▸ Edit properties…**
2. Change **Title**, **Author**, **Subject** or **Keywords**. Separate keywords with commas.
3. Click **Save properties**.

> **Note:** The change is made to the open document and can be undone. See [Undo and redo](#topic:undo-redo). It reaches the file on disk when you save. See [Save and print](#topic:save-and-print).

> **Tip:** Title and Author help other people find the file. If you share a PDF, check them first, because they may show a name or title you would rather not pass on.

Both commands are disabled when no document is open. **Edit properties…** is also unavailable for read-only documents.
