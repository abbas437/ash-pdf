# Take a snapshot of part of a page

Snapshot turns any rectangle on a page into a picture. You can paste it into another program or save it as a PNG file.

## Take a snapshot

1. Choose **View ▸ Snapshot…**. The menu item is available only while a document is open.
2. A hint appears: "Drag over a page to take a snapshot. Esc cancels."
3. Drag a rectangle over the area you want, on a single page. A click without a drag does nothing, so you can try again.
4. When you release the mouse button, the **Snapshot** window opens with a preview.

To cancel, press **Esc**, click outside the page area, or switch to another tab.

## What you can do with it

The preview window has three buttons:

- **Copy** puts the picture on the clipboard and shows "Snapshot copied". The window stays open, so you can copy again or save as well.
- **Save as PNG…** asks where to save. The suggested name is the document name, the page number and "snapshot", for example `Report-p3-snapshot.png`.
- **Close** closes the window without doing anything else.

> **Tip:** Paste straight into Word, an email or a chat. If the other program does not accept pictures, it receives a short text description instead.

## Resolution and content

The area is drawn at twice its size in the PDF (2 pixels per point), so text stays sharp when you paste it into a document. Below the preview, the window shows the page number, the size of the area in points, and the size of the picture in pixels.

The snapshot includes the page as you see it:

- annotations and form fields;
- objects you have placed but not yet saved, such as text boxes and pictures;
- only the layers that are currently visible.

> **Note:** The picture is a plain image. It does not keep the text, so it cannot be searched or selected. To make a scanned page searchable, see [Recognise text (OCR)](#topic:ocr). To save whole pages as images, see [Export to Word, Excel or an image](#topic:export-word-excel-image).
