# Sticky notes

A sticky note is a small icon on the page that holds a longer comment. Use it when the remark is not about one particular piece of text.

[Show me](#showme:tool:note)

## Add a note

1. Press <kbd>N</kbd> or click the Sticky note tool.
2. In the options bar, choose an icon (see below).
3. Click where the icon should sit. A popup opens, headed with the author name and the date.
4. Type the comment.
5. Click **Save**, or press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.

**Cancel** or <kbd>Esc</kbd> closes the popup without saving. Clicking elsewhere on the page saves it.

> **Tip:** The author shown is your configured name; see [Author name](#topic:author-name).

## Icons

The icon list offers six symbols: Comment (the default), Note, Key, Help, Paragraph and Insert. They are only a visual cue; the note text works the same for all of them.

You can change the icon later: open the note and pick another icon from the list in the popup, then save.

## Open or edit a note

- Double-click the icon, with any tool active.
- With the Sticky note tool active, click an existing icon.
- Select any object and press <kbd>Enter</kbd> to give it a comment of its own.

Drag the icon with the Select tool to move it. Select it and delete it to remove it.
